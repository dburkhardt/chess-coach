# Current Game visual references

These images are generated by `ChessBoardVisualTests` at the app's default and
minimum supported window sizes. They cover the native navigation, player strip,
board, move-history treatment, and compact layout used for visual regression
review.

The test also renders the complete Coach split in its temporary output. The
committed references stop at the gameplay area because macOS platform text
fields and menus do not flatten faithfully through SwiftUI `ImageRenderer`.
